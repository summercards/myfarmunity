## 📋 v1.1 项目目标回顾

### 四大主要目标（G1-G4）

| 目标 | 描述 | 当前状态 |
|------|------|----------|
| **G1** | NPC成为"独立个体"（Actor） | ✅ 已有基础架构 |
| **G2** | 模块化（台词/属性/技能），保持轻量 | ⏳ 需要新增模块 |
| **G3** | NPC可独立调度（低频tick） | ⏳ 需要新增ActorTickModule |
| **G4** | 扩展性与迁移友好 | ⏳ 需要验证 |

### 五大验收口径

1. 主链路不回退：对话打开/切换/关闭、商店等功能仍可用
2. 台词模块化：至少2组台词能按简单条件切换
3. 属性模块化：至少1个NPC可读写属性条目
4. 技能模块化：至少1个NPC可触发技能且有冷却
5. 独立调度：至少1个NPC开启低频tick，并且没有新增大量Update()
