## 附录

### 参考设计

**卧室布局设计**：
```
    +-------------------+
    |                   |
    |     [床]          |  ← 灵之空间入口
    |                   |
    |      [衣柜]        |
    |                   |
    |  [桌子]  [椅子]    |
    |                   |
    |    [门] ← 传送出口  |  ← 云层电梯传送入口
    +-------------------+
        ↑    ↑    ↑
      窗户  画   地毯
```

**传送流程设计**：
```
云层电梯 → 传送动画（淡入淡出） → 卧室
卧室 → 点击传送出口 → 传送动画 → 云层电梯
卧室 → 点击床 → 睡觉动画 → 传送动画 → 灵之空间
```

**DIY功能设计**：
- 点击家具 → 进入放置模式
- 移动鼠标 → 家具跟随移动
- 点击左键 → 确认放置
- 右键点击家具 → 删除家具
- 保存按钮 → 保存当前DIY配置
- 加载按钮 → 加载保存的DIY配置
