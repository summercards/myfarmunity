## 使用说明

1. 新增任务时，沿用所在阶段的编号段，避免冲突。
2. 状态字段支持：`todo` / `in_progress` / `done`。
3. 进度字段范围：`0-100`。

## 默认归属
- 文档：施工文档 v1.2
- 阶段：卧室功能开发

## 新增任务模板（示例，不会被解析）
```md

```
