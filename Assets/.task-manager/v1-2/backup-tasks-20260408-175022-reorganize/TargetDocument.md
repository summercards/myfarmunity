# 我的农场 v1.2 Target Document

## Version Summary

完成卧室功能闭环（不含美术）：云层↔卧室传送、卧室DIY、床睡觉进入灵之空间、唯一入口治理、存档兼容与发布回归。

## Version Goal

完成主角私人卧室的功能版交付（抛开美术模块），包括：
- ✅ 云层电梯与卧室双向传送可用
- ✅ 卧室支持DIY基础能力（放置、移动、删除）
- ✅ 卧室DIY数据可保存并恢复
- ✅ 床交互可触发睡觉并进入灵之空间
- ✅ 卧室是灵之空间唯一入口
- ✅ 不破坏现有云层/NPC/商店/移动/存档流程

## Stages

### 版本目标与范围

- **Status**: todo
- **Summary**: 明确 v1.2 功能边界与必须达成的闭环能力（不含美术）

#### 纳入范围（必须完成）

1. **场景与入口基础**
   - 新建卧室功能场景（可白模）
   - 新建灵之空间入口场景（可空场景）
   - Build Settings 正确配置场景

2. **传送系统（复用现有框架）**
   - 复用 `Portal` + `PortalManager` + `SpawnPoint`
   - 云层电梯↔卧室双向传送
   - 卧室床交互→灵之空间传送

3. **DIY系统基础**
   - 家具放置、移动、删除
   - 卧室内可编辑区域约束
   - 编辑态与玩家移动/交互兼容

4. **数据持久化**
   - 优先接入 `SaveManager` (`ISaveParticipant`)
   - 无 `SaveManager` 时允许 PlayerPrefs fallback
   - DIY数据可跨读档恢复

5. **灵之空间唯一入口治理**
   - 排查并禁用非卧室床入口
   - 增加配置校验清单，防止后续误加入口

#### 不纳入范围（后续版本）

- ❌ 卧室成品美术替换（白模→成品）
- ❌ 音效、粒子、光照精修
- ❌ 灵之空间玩法内容（本版本只做入口）
- ❌ 卧室NPC交互（商人、剧情对话等）
- ❌ 多房间扩展与室外联动

#### 验收标准

**功能验收**：
- [ ] 云层电梯→卧室传送正常
- [ ] 卧室→云层电梯传送正常
- [ ] 床交互可触发睡觉并进入灵之空间
- [ ] DIY可放置、移动、删除至少3类家具
- [ ] DIY数据保存后重启/读档可恢复
- [ ] 灵之空间仅可通过卧室床进入

**兼容性验收**：
- [ ] 不影响现有云层功能
- [ ] 不影响现有NPC对话系统
- [ ] 不影响现有商店功能
- [ ] 不影响玩家移动与主循环

**存档验收**：
- [ ] 有 `SaveManager` 时按统一存档流程生效
- [ ] 无 `SaveManager` 场景下 fallback 正常
- [ ] 多次保存/读取不出现重复生成或丢失

### 架构约束

- 传送统一走 `Portal/PortalManager`，避免并行实现。
- 存档统一遵循 `SaveManager` 优先策略。
- 新增灵之空间入口必须通过“唯一入口治理”校验。
